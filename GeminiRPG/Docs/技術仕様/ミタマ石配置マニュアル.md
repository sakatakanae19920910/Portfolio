**対象スクリプト**: `MitamaStoneItem.cs` / `MitamaCountUI.cs`

## 全体のミタマ石設計

デモでは合計 **7個** のミタマ石が存在し、プレイヤーが7個すべてを集めると交換屋できらきら星と交換できる。

| 入手方法 | 場所 | 個数 | 実装方法 |
|----------|------|------|----------|
| フィールド拾得（接触） | TownScene | 3個 | `MitamaStoneItem.cs`（このマニュアルで設定） |
| 武器屋店主（初回） | WeaponShopScene | 1個 | CSV `NPC_WeaponShopOwner.csv` ← 実装済み |
| 狩人（初回） | WeaponShopScene | 1個 | CSV `NPC_WeaponShopHunter.csv` ← 実装済み |
| やさぐれた男性（初回） | TavernScene | 1個 | CSV `NPC_TavernGrump.csv` ← 実装済み（シーン未作成） |
| 小柄な子供（初回） | TavernScene | 1個 | CSV `NPC_TavernChild.csv` ← 実装済み（シーン未作成） |
| **合計** | | **7個** | |

> ⚠️ TavernScene は 5/21 完成予定のため、それまでは最大5個しか集まらない（テスト時は注意）

## ミタマ石のスプライト準備

ミタマ石専用スプライトを用意するか、FSMタイルの宝石素材（光るオブジェクト）を代用する。

### 推奨サイズ
- **48×48 px**（PPU=48 の設定に合わせる）

### 手順
1. スプライト画像を `Assets/Art/Items/` に配置（フォルダがなければ作成）
2. インポート設定:
   - **Texture Type**: Sprite (2D and UI)
   - **Pixels Per Unit**: 48
   - **Filter Mode**: Point (no filter)  ← ドット絵をくっきり表示するために必要
3. Apply

> 💡 **暫定対応**: まだ専用スプライトがない場合は、FSMタイル素材の光るオブジェクト画像、または Unity の `Default-Sprite`（白い丸）を使ってパーティクルで代用してもOK。後から差し替えるだけでよい。

## フィールドミタマ石のセットアップ（1個ぶん）

以下を3回繰り返して TownScene に3個配置する。

### Step 1: GameObject 作成

**Hierarchy ウィンドウ** で:
1. `+` → **Create Empty** → 名前を `MitamaStone_Town01` に変更
   - 2個目: `MitamaStone_Town02`、3個目: `MitamaStone_Town03`

---

### Step 2: SpriteRenderer 追加

1. MitamaStone_Town01 を選択
2. **Add Component** → `Sprite Renderer`
3. **Sprite** フィールドに用意したミタマ石スプライトをアサイン
4. **Order in Layer**: `1`（タイルマップより手前に表示するため）

---

### Step 3: Collider2D 追加

1. **Add Component** → `Circle Collider 2D`
2. **Radius**: `0.3`（スプライトの大きさに合わせて調整）
3. **isTrigger** はチェックしなくてよい（`MitamaStoneItem.cs` が自動でONにする）

---

### Step 4: MitamaStoneItem スクリプトをアタッチ

1. **Add Component** → `MitamaStoneItem`
2. Inspector で以下を設定:

   | フィールド | 設定値 |
   |-----------|--------|
   | **Stone ID** | `Town_01`（2個目は `Town_02`、3個目は `Town_03`） |
   | **Pickup CSV** | `Demo_MitamaStone_Pickup`（Resourcesから検索してアサイン） |

   > ⚠️ Stone ID は **シーン全体でユニーク**にすること。他のシーンに石を追加する場合も `Tavern_01` など被らない名前にする。

---

### Step 5: シーンに配置

**Scene ビュー** で石を適切な場所にドラッグ。

#### TownScene 推奨配置場所（3個）

| 名前 | 推奨配置場所 | 理由 |
|------|------------|------|
| `Town_01` | 町の入口付近（目につきやすい道） | 最初に気づいてもらうため |
| `Town_02` | 路地裏や建物の横 | 探索を促すため |
| `Town_03` | 交換屋の近くや広場 | 探索を広げてもらうため |

> 💡 **配置のコツ**: 道の上に置くと踏みやすい。壁の隅に置くと「隠れた宝」感が出る。

---

### Step 6: プレイヤータグの確認

`MitamaStoneItem.cs` は `CompareTag("Player")` でプレイヤーを判定する。  
Player GameObject に `Player` タグが設定されているか確認する。

1. Hierarchy の `Player`（または Player Prefab）を選択
2. Inspector 上部の **Tag** ドロップダウンが `Player` になっているか確認

---

## ミタマ石所持数HUD のセットアップ

各探索シーン（TownScene、TraderScene、WeaponShopScene、TavernScene）に設置する。

### Step 1: Canvas に UI を追加

1. Hierarchy の `Canvas` を展開
2. `Canvas` を右クリック → **UI** → **Text - TextMeshPro** → 名前を `MitamaCountText` に変更

---

### Step 2: テキストの配置（右上固定）

RectTransform の設定:

| 設定項目 | 値 |
|---------|-----|
| **Anchor Presets** | 右上（Top-Right）を選択 |
| **Pivot X** | 1 |
| **Pivot Y** | 1 |
| **Anchor Pos X** | -20 |
| **Anchor Pos Y** | -20 |
| **Width** | 200 |
| **Height** | 40 |

---

### Step 3: テキストのスタイル設定

| 設定項目 | 推奨値 |
|---------|--------|
| **Font Asset** | KleeOne-Regular SDF |
| **Font Size** | 24 |
| **Alignment** | Right（右揃え） |
| **Color** | 白 `#FFFFFF` |
| **Text** | （初期値は空でOK） |

---

### Step 4: MitamaCountUI スクリプトをアタッチ

1. `MitamaCountText` を選択
2. **Add Component** → `MitamaCountUI`
3. Inspector で設定:

   | フィールド | 設定値 |
   |-----------|--------|
   | **Count Text** | `MitamaCountText`（自分自身の TextMeshPro をアサイン） |
   | **Format** | `ミタマ石 × {0}`（デフォルトのままでOK） |
   | **Hide When Zero** | `false`（常に表示）または `true`（占い師に会うまで非表示） |

> 💡 **Hide When Zero = true** にすると、まだ石を1個も持っていない間は表示されず、初めて拾った瞬間に「ミタマ石 × 1」と現れる。演出的にこちらがおすすめ。

## 動作確認チェックリスト

設置後、以下を確認する。

### フィールド石の拾得
- [ ] プレイヤーが石に近づいて接触すると「ミタマ石を手に入れた！」が表示される
- [ ] クリック/Enterで閉じるとプレイヤーが動き始める
- [ ] 石のオブジェクトが消える
- [ ] 同じ場所を通り直しても石が再出現しない（シーン再訪時も非表示のまま）
- [ ] 右上のHUDに `ミタマ石 × 1` と表示される

### NPC経由の入手（武器屋）
- [ ] 武器屋店主に話しかけると「ミタマ石を手に入れた！」が出る
- [ ] HUDのカウントが増える
- [ ] 2回目以降は「うちは情報交換の場として〜」に切り替わる

### 交換屋での分岐
- [ ] 7個未満の場合「あと○つで交換できますよ」と個数が正しく表示される
- [ ] 7個集まると「きらきら星と交換しますか？」に切り替わる

### シーンをまたいだ永続化
- [ ] TownSceneで石を拾ってからTraderSceneに移動しても所持数が引き継がれる
- [ ] TownSceneに戻っても拾った石は復活しない

## よくあるミス

| 症状 | 原因 | 対処 |
|------|------|------|
| 石に触れても何も起きない | Player タグが設定されていない | Playerに `Player` タグをセット |
| 石に触れても何も起きない（2） | Collider2D がない、またはレイヤー問題 | `Circle Collider 2D` を確認 |
| 「ミタマ石を手に入れた！」が出ない | Pickup CSV が未アサイン | Inspector で `Demo_MitamaStone_Pickup` をアサイン |
| 会話が終わっても動けない | ScenarioExecutor が見つからない | シーンにScenarioExecutor（DialogSystemPrefab）があるか確認 |
| HUDが更新されない | Count Text が未アサイン | MitamaCountUI の Count Text フィールドを確認 |
| 同じ石を何度も拾える | Stone ID が空または重複している | 各石にユニークな Stone ID を設定 |
| TavernSceneで石が0個 | TavernScene未完成 | 酒場シーン完成後に確認（5/21以降） |
