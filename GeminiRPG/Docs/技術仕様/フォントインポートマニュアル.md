# フォントインポートマニュアル

**作成日**: 2026-05-13
**対象**: Unity + TextMeshPro でのフォント追加手順

---

## このプロジェクトで使うフォント

| フォント名 | 用途 | 入手先 |
|-----------|------|--------|
| **Klee One** | 会話テキスト（メイン） | Google Fonts |
| **Shippori Mincho** | 話者名・見出し | Google Fonts |

---

## Step 1: フォントファイルをダウンロードする

Google Fonts（[fonts.google.com](https://fonts.google.com)）からダウンロードする。

```
Klee One      → 検索: "Klee One"
Shippori Mincho → 検索: "Shippori Mincho"
```

1. フォントページを開く
2. 右上の「**Download family**」ボタンをクリック
3. ZIPが落ちてくるので解凍する
4. 中にある `.ttf` ファイルを取り出す

```
KleeOne-Regular.ttf
KleeOne-SemiBold.ttf
ShipporiMincho-Regular.ttf
ShipporiMincho-Bold.ttf
など
```

> **どのウェイトを使うか**: 会話テキストは Regular、話者名は SemiBold/Bold が読みやすい。まずは Regular だけ入れればOK。

---

## Step 2: Unityにフォントを取り込む

### フォルダを作る

Projectウィンドウで右クリック → Create → Folder

```
Assets/
  Fonts/          ← ここを作る
    KleeOne/
    ShipporiMincho/
```

### .ttf ファイルをドラッグ

OS のファイルマネージャ（Finder）から `.ttf` を、作ったフォルダにドラッグ&ドロップする。

```
Assets/Fonts/KleeOne/
  KleeOne-Regular.ttf      ← これ
  KleeOne-SemiBold.ttf

Assets/Fonts/ShipporiMincho/
  ShipporiMincho-Regular.ttf
```

インポートが完了すると、Projectウィンドウに白いフォントアイコンが現れる。

---

## Step 3: TextMeshPro Font Asset を作る

Unity の TextMeshPro は `.ttf` を直接使わず、**Font Asset**（`.asset`）に変換して使う。

Font Asset = Unity が文字を描画するためのテクスチャとメタデータをまとめたファイル。

### 変換手順

1. Projectウィンドウで `.ttf` ファイルを右クリック
2. **「Create > TextMeshPro > Font Asset」** を選ぶ
3. 同じフォルダに `.asset` ファイルが作られる

```
Assets/Fonts/KleeOne/
  KleeOne-Regular.ttf
  KleeOne-Regular SDF.asset   ← これが作られる（SDF = テキスト描画形式）
```

> **「SDF」とは**: Signed Distance Field の略。拡大・縮小しても文字がぼやけない描画方式。TextMeshPro はこの形式を使う。

### 2種類のフォント分、同じ手順を繰り返す

- `KleeOne-Regular.ttf` → Font Asset 作成
- `ShipporiMincho-Regular.ttf` → Font Asset 作成

---

## Step 4: Fallback Font を設定する（日本語全文字を表示するために重要）

デフォルトのFont Assetは**よく使う文字しか含まれていない**。  
珍しい漢字や記号が□（豆腐）になる場合は Fallback を設定する。

### 設定方法

1. 作った Font Asset をダブルクリック → Inspectorに設定画面が開く
2. 下の方に **「Fallback Font Assets」** というリストがある
3. 「＋」ボタンを押して、別の Font Asset を追加する

```
実用的な Fallback 構成:
KleeOne-Regular SDF
  └ Fallback: NotoSansJP-Regular SDF（Noto Sans JP をダウンロードして追加）
```

> **デモ段階では**: 使う文字が限られているので Fallback なしでも動く。文字化けが起きたら対処すればOK。

---

## Step 5: TextMeshPro コンポーネントにフォントを適用する

### Prefab に適用する（推奨）

`DialogueSystem.prefab` をダブルクリックして Prefab 編集モードに入る。

```
DialogueSystem
  ├ DialoguePanel
  │   └ MainText        ← ここに Klee One を設定
  └ SpeakerPanel
      └ SpeakerText     ← ここに Shippori Mincho または Klee One SemiBold を設定
```

1. `MainText` を選択 → Inspector を見る
2. TextMeshPro コンポーネントの **「Font Asset」** 欄にFont Assetをドラッグ
3. `SpeakerText` にも同様に設定
4. Prefab 編集モードを終了（左上の「＜」）

Prefab に設定すれば全シーンに自動反映される。

### フォントサイズ・行間の確認

| 設定項目 | 推奨値 | 場所 |
|---------|-------|------|
| Font Size（MainText） | 24〜28 | TextMeshPro > Font Size |
| Line Spacing | 0〜5 | TextMeshPro > Line Spacing |
| Font Size（SpeakerText） | 20〜24 | TextMeshPro > Font Size |

Game view でテキストを実際に流して、読みやすいサイズに調整する。

---

## よくある問題

### 「文字が□（豆腐）になる」

原因: その文字が Font Asset のテクスチャに含まれていない。

対処:
1. Font Asset を Inspector で開く
2. 下部の **「Update Asset」** ボタンを押す（使用中の文字を再スキャンして追加）
3. それでも出ない場合は Fallback Font を設定する（Step 4）

---

### 「フォントが変わっていない」

原因: Prefab の Apply が済んでいないか、シーン内のインスタンスを直接変えた。

対処: Prefab をダブルクリックして編集モードで変更する。

---

### 「フォントが太すぎる / 細すぎる」

原因: ウェイト（Regular / SemiBold / Bold）が合っていない。

対処: 別ウェイトの `.ttf` を追加でインポートして Font Asset を作り、使い分ける。

---

## まとめ

```
フォント追加の流れ

1. Google Fonts から .ttf をダウンロード
2. Assets/Fonts/ にドラッグ
3. .ttf を右クリック → Create > TextMeshPro > Font Asset
4. Prefabのテキストコンポーネントに Font Asset をドラッグ
5. Game view で見た目を確認・フォントサイズ調整
```
