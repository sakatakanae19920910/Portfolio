# アニメーション素材マニュアル

**作成日**: 2026-05-20  
**対象**: フィールド上のキラキラ・光るオブジェクト（ミタマ石・本棚・インタラクト可能オブジェクト等）

---

## 方法の選択肢

| 方法                            | 向いている用途                     | 工数   |
| ------------------------------- | ---------------------------------- | ------ |
| **A. スプライトアニメーション** | 石そのものがキラッと光る・点滅する | 低     |
| **B. Particle System**          | 周囲に光の粒が漂う・星が飛ぶ       | 中     |
| **C. A+B 組み合わせ**           | 本格的なキラキラ演出               | 中〜高 |

ミタマ石・本棚には **B（Particle System）** が最速でそれらしく見える。

---

## 方法A: スプライトアニメーション

石そのものを点滅・拡縮させる。素材が1枚あればできる。

### 手順

1. **Animation ウィンドウを開く**  
   Window → Animation → Animation

2. **アニメーションを作成**  
   - 対象 GameObject（例：MitamaStone）を Hierarchy で選択  
   - Animation ウィンドウの **Create** をクリック  
   - 保存先: `Assets/Animations/Field/MitamaStone_Glow.anim`

3. **キーフレームを打つ（点滅の例）**  
   - `SpriteRenderer.color` を Record モードで操作  
   - 0:00 → alpha=1（通常）  
   - 0:30 → alpha=0.3（暗く）  
   - 1:00 → alpha=1（元に戻る）  
   - ループ設定（Inspector → Loop Time: ON）

4. **Animator Controller を作成**  
   - Project で右クリック → Create → Animator Controller  
   - 保存: `Assets/Animations/Field/MitamaStone.controller`  
   - Animator ウィンドウで作成した .anim をドラッグして Default State に設定  
   - MitamaStone の GameObject に Animator コンポーネントを追加し Controller を割り当て

### 代替: DOTween で点滅（コードで実装）
素材不要で一番手軽。`MitamaStoneItem.cs` に追記するだけ。

```csharp
// Start() に追加
GetComponent<SpriteRenderer>().DOFade(0.3f, 0.8f)
    .SetLoops(-1, LoopType.Yoyo)  // 無限に繰り返す
    .SetEase(Ease.InOutSine);
```

## 方法B: Particle System（推奨）

GameObject の周囲に光の粒が浮かぶ演出。素材不要でも動くが、専用テクスチャがあると本格的。

### 手順

1. **Particle System を追加**  
   - MitamaStone の GameObject を右クリック → Effects → Particle System  
   - MitamaStone の子 GameObject として作成される

2. **推奨パラメータ（キラキラ星）**

   | パラメータ                    | 値                                 | 場所     |
   | ----------------------------- | ---------------------------------- | -------- |
   | Duration                      | 1                                  | 最上部   |
   | Looping                       | ON                                 | 最上部   |
   | Start Lifetime                | 1〜2                               | 最上部   |
   | Start Speed                   | 0.3〜0.8                           | 最上部   |
   | Start Size                    | 0.05〜0.15                         | 最上部   |
   | Start Color                   | ライトシアン〜白                   | 最上部   |
   | Gravity Modifier              | -0.1（ゆっくり上昇）               | 最上部   |
   | Max Particles                 | 8〜12                              | 最上部   |
   | **Emission > Rate over Time** | 5                                  | Emission |
   | **Shape > Shape**             | Circle / Radius 0.3                | Shape    |
   | **Renderer > Render Mode**    | Billboard                          | Renderer |
   | **Renderer > Material**       | Default-Particle（または専用素材） | Renderer |

3. **Sorting Order を合わせる**  
   Renderer → Order in Layer を MitamaStone の SpriteRenderer より大きい値に設定（例：+1）  
   ※ 数値が大きいほど手前に表示される

4. **色を世界観に合わせる**  
   Start Color を Gradient にして `#44BFA3`（ミタマ石の着色色）〜白でグラデーション設定すると統一感が出る

## 方法C: A + B の組み合わせ

1. **石本体**: DOTween で微妙に上下にゆれる（ホバリング）
2. **パーティクル**: 周囲にキラキラ

```csharp
// MitamaStoneItem.cs の Start() に追加
// ゆらゆら上下に浮かぶ
transform.DOMoveY(transform.position.y + 0.1f, 1.2f)
    .SetLoops(-1, LoopType.Yoyo)
    .SetEase(Ease.InOutSine);
```

## 本棚・インタラクト可能オブジェクトへの応用

同じ方法で「調べられる」オブジェクトをわかりやすく光らせられる。

| オブジェクト | 推奨方法                            | 色                  |
| ------------ | ----------------------------------- | ------------------- |
| ミタマ石     | B or C                              | `#44BFA3`（シアン） |
| 本棚         | A（点滅）or B（小さいパーティクル） | 暖色（#FFD580）     |
| 宝箱         | B（少し派手め）                     | 金色（#FFD700）     |

## ミタマ石への最速実装手順（コード追加のみ）

`MitamaStoneItem.cs` の `Start()` に以下を追加するだけ。素材不要。

```csharp
void Start()
{
    // 既存コードの後に追加 ↓

    // ゆらゆら上下に浮かぶ
    transform.DOMoveY(transform.position.y + 0.08f, 1.0f)
        .SetLoops(-1, LoopType.Yoyo)
        .SetEase(Ease.InOutSine);

    // キラッと点滅
    GetComponent<SpriteRenderer>().DOFade(0.6f, 0.6f)
        .SetLoops(-1, LoopType.Yoyo)
        .SetEase(Ease.InOutSine);
}
```

Particle System も追加するなら上記に加えてシーン上で子 GameObject として設置する。

## 注意事項

- **拾得後はアニメーションを止める**: `MitamaStoneItem.cs` の拾得処理（`gameObject.SetActive(false)`）でアニメーションも一緒に停止する。DOTween は `DOTween.Kill(transform)` で止められる
- **WebGL でのパーティクル**: WebGL でも動作するが、パーティクル数が多いとモバイルで重くなる。Max Particles は 15 以下を推奨
- **Sorting Layer**: パーティクルが建物の後ろに隠れる場合は Sorting Layer を "Objects" または "UI" に変更する
