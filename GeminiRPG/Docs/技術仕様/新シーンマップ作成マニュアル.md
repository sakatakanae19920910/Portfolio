# 新シーンマップ作成マニュアル

**作成日**: 2026-05-13
**対象**: このプロジェクトで新しくマップシーンを作るときの手順

---

## このマニュアルで作れるもの

プレイヤーが歩き回れる**フィールドシーン**（TownScene・PartnerHouse1FScene のようなもの）。

- プレイヤー（歩行・当たり判定）
- カメラ追従
- タイルマップ（地面・建物・コリジョン）
- 会話UI（DialogueSystem Prefab）
- フェード演出
- NPCとの会話トリガー
- 別シーンへの遷移

---

## 全体の流れ

```
1. シーンを作成 → Build Settings に追加
2. Tilemapの階層を組む
3. プレイヤーを配置
4. カメラを設定
5. DialogueSystem Prefabを置く
6. FadeCanvas を置く
7. NPCを配置する（必要に応じて）
8. マップ遷移を設定する（必要に応じて）
9. 動作確認
```

---

## Step 1: シーンを作る

### 新規シーンを作成

1. Unityメニュー: **File > New Scene**
2. **「Basic 2D」** テンプレートを選ぶ（Main Camera が最初から入る）
3. Ctrl+S（Mac: Cmd+S）で保存
4. 保存先: `Assets/Scenes/`
5. ファイル名例: `PartnerHouse2FScene.unity`

### Build Settings に追加

**File > Build Settings** を開く。

「Add Open Scenes」ボタンをクリック → 今開いているシーンが追加される。

```
Scenes in Build:
  0: Scenes/BootScene      ← 番号0は最初に起動するシーンなので変えない
  1: Scenes/TitleScene
  2: Scenes/IntroScene
  3: Scenes/TownScene
  4: Scenes/PartnerHouse1FScene
  5: Scenes/PartnerHouse2FScene  ← 追加した
```

> **MapTransition でシーン遷移するには必須**。Build Settings に入っていないシーンへは遷移できない。

---

## Step 2: Tilemap の階層を組む

### Grid オブジェクトを作る

Hierarchy で右クリック → **「2D Object > Tilemap > Rectangular」**

これを選ぶと自動で以下が作られる:

```
Grid
  └ Tilemap  ← TilemapRenderer も自動でつく
```

### Grid の名前を変える

`Grid` を選択 → Inspector の一番上の名前欄を **`TownMap_Grid`** に変更。

### Tilemap レイヤーを 6 層作る

このプロジェクトは以下の 6 レイヤー構成が標準。

| レイヤー名 | 用途 | Sorting Order |
|-----------|------|--------------|
| **Ground** | 地面・草 | 0 |
| **Path** | 道・広場 | 1 |
| **Buildings** | 建物の壁 | 2 |
| **Objects** | 木・岩・装飾物 | 3 |
| **Rooftop** | 屋根 | 4 |
| **Collision** | 当たり判定（非表示） | 0 |

最初に作られた `Tilemap` を `Ground` にリネームする。残り 5 つは Grid を右クリック → **「2D Object > Tilemap > Rectangular」** で追加して名前をつける。

```
TownMap_Grid
  ├ Ground        ← Sorting Order: 0
  ├ Path          ← Sorting Order: 1
  ├ Buildings     ← Sorting Order: 2
  ├ Objects       ← Sorting Order: 3
  ├ Rooftop       ← Sorting Order: 4
  └ Collision     ← Sorting Order: 0（非表示）
```

### 各 Tilemap の Sorting Order を設定する

各子オブジェクトを選択 → Inspector の **Tilemap Renderer > Order in Layer** に数値を入力。

### Collision レイヤーの特殊設定

`Collision` を選択して以下を設定する:

1. **Tilemap Renderer のチェックを外す**（非表示にする）
   - Inspector の Tilemap Renderer コンポーネント左のチェックボックスをオフ
2. **TilemapCollider2D を追加**
   - Add Component → `TilemapCollider2D`
3. **Rigidbody2D を追加**（Static）
   - Add Component → `Rigidbody2D`
   - Body Type を **Static** に変更
4. **CompositeCollider2D を追加**
   - Add Component → `CompositeCollider2D`
5. **TilemapCollider2D の「Used By Composite」をオン**
   - Inspector の TilemapCollider2D > Used By Composite にチェック

> Composite を使うと複数のタイルの当たり判定がひとつにまとまり、処理が速くなる。

### TownMapBuilder でタイルを自動配置する場合

上記の階層を手動で作らなくても、**GeminiRPG > Build Town Map** を実行すれば自動で作られる。CSVと TileMappingアセットが必要。手動配置の場合はこのStepをそのまま使う。

## Step 3: プレイヤーを配置する

### Player オブジェクトを作る

Hierarchy で右クリック → **「2D Object > Sprite」**

名前を `Player` に変更。

### タグを設定する

Inspector の **「Tag」** ドロップダウン → **「Player」** を選ぶ。

> CameraFollow・NPCTrigger・MapTransition がこのタグでプレイヤーを検索する。必須。

### スプライトを設定する

Inspector の Sprite Renderer > **Sprite** 欄に、キャラチップのスプライト（Idle/Down の1枚）をドラッグ。

### コンポーネントを追加する

Add Component から順番に追加する:

| コンポーネント | 設定 |
|--------------|------|
| **Rigidbody2D** | Body Type: Dynamic / Gravity Scale: 0 / Constraints: Freeze Rotation Z にチェック |
| **CapsuleCollider2D** | Size を調整（キャラの足元に合わせる） |
| **PlayerController** | `Assets/Scripts/Player/PlayerController.cs` |
| **Animator** | 対応する Animator Controller をアサイン |

### PlayerController の設定

`PlayerController` を追加したら、Inspector で以下を確認する:

| 設定項目 | 値 |
|---------|-----|
| Move Speed | 3〜5 |
| Input Actions | `InputSystem_Actions` アセットをドラッグ |

`InputSystem_Actions` は `Assets/` 直下にある。見つからない場合は Project ウィンドウで `InputSystem_Actions` と検索。

---

## Step 4: カメラを設定する

### Main Camera に CameraFollow を追加

Hierarchy の **Main Camera** を選択 → Add Component → `CameraFollow`

### CameraFollow の設定

| 設定項目 | 値 | 説明 |
|---------|-----|------|
| Auto Find Player | オン（チェック） | Playerタグを自動検索する |
| Smooth Speed | 5 | 追従の滑らかさ |
| Offset | (0, 0, -10) | Z=-10 は必須（2Dでカメラは手前に置く） |
| Use Boundary | 任意 | マップ端でカメラを止めたい場合はオン |

### Camera の Orthographic Size を確認

Main Camera の Inspector > **Camera > Orthographic Size**。

値が大きいほどズームアウト。`5` あたりから始めて Game view で調整する。

---

## Step 5: DialogueSystem Prefab を置く

### Prefab をドラッグ

Project ウィンドウの **`Assets/_Prefabs/DialogueSystem.prefab`** を Hierarchy にドラッグ。

これだけで会話UIの一式（Canvas・ScenarioExecutor・テキストボックス）がシーンに置かれる。

> ⚠️ **参照の確認が必要**: ScenarioExecutor の各フィールド（SpeakerText, MainText, ChoiceContainer 等）が空欄でないか確認する。Prefabが正しく Apply されていれば空欄にならないはず。もし空欄なら [Prefabマニュアル.md](Prefabマニュアル.md) の「よくある失敗」を参照。

---

## Step 6: FadeCanvas を置く

FadeManager はシングルトン（`DontDestroyOnLoad`）なので、**BootScene から引き継がれる**。  
新しいシーンに別途置く必要はない。

> **BootScene を経由せず直接シーンを再生する場合**（Unityエディタ上でのテスト）は FadeManager が存在しないため、フェードなしで動く。これはテスト時の正常な挙動なので問題ない。

---

## Step 7: NPC を配置する（必要に応じて）

### NPC オブジェクトを作る

Hierarchy で右クリック → **「2D Object > Sprite」**

名前を NPC の名前に変更（例: `NPC_Merchant`）。

### スプライトを設定する

NPC のキャラチップ（立っている1枚）を Sprite Renderer > Sprite にドラッグ。

### コンポーネントを追加する

| コンポーネント | 設定 |
|--------------|------|
| **BoxCollider2D** | Is Trigger: **オン** |
| **NPCTrigger** | `Assets/Scripts/Player/NPCTrigger.cs` |

### NPCTrigger の設定

| 設定項目 | 値 |
|---------|-----|
| Scenario CSV | 会話シナリオの CSV ファイルをドラッグ |
| Start Label | 空欄（最初から）または特定ラベル名 |
| Input Actions | `InputSystem_Actions` をドラッグ |

> CSV はシナリオシステムのマニュアルを参照: [シナリオシステム.md](機能仕様書/シナリオシステム.md)

---

## Step 8: マップ遷移を設定する（必要に応じて）

ドア・階段・マップ端など、別のシーンやエリアへ移動するポイントに設定する。

### 遷移ポイントを作る

Hierarchy で右クリック → **「Create Empty」**

名前の例: `TransitionToTown`, `SpawnFromTown`

### コンポーネントを追加する

| コンポーネント | 設定 |
|--------------|------|
| **BoxCollider2D** | Is Trigger: **オン** / サイズはキャラ1〜2タイル分 |
| **MapTransition** | `Assets/Scripts/Player/MapTransition.cs` |

### MapTransition の設定

**別シーンへ遷移する場合（TransitionType: SceneChange）**:

| 設定項目 | 値 | 例 |
|---------|-----|-----|
| Transition Type | Scene Change | |
| Target Scene Name | 遷移先のシーン名 | `TownScene` |
| Spawn Point Name | 遷移先のスポーンポイント名 | `SpawnFromHouse` |
| Use Fade | オン | |

**同一シーン内でテレポートする場合（TransitionType: Teleport）**:

| 設定項目 | 値 |
|---------|-----|
| Transition Type | Teleport |
| Teleport Destination | 移動先の Transform をドラッグ |
| Arrival Direction | 到着時の向き（下向き = (0, -1)） |

### スポーンポイントを作る（シーン遷移を使う場合）

遷移先のシーンに **スポーンポイントオブジェクト** を置く。

1. Hierarchy で右クリック → **「Create Empty」**
2. 名前を `SpawnFromTown` などに変更（MapTransition の `Spawn Point Name` と一致させる）
3. ドア・階段の前あたりに位置を合わせる

MapTransition.cs はシーンロード後に `nextSpawnPointName` という名前のオブジェクトを探し、プレイヤーをその位置に配置する。

## Step 9: 動作確認チェックリスト

再生する前に確認する。

```
シーン構成
  [ ] シーンが Build Settings に追加されている
  [ ] Player オブジェクトに「Player」タグが設定されている
  [ ] Player に Rigidbody2D（Gravity Scale: 0）がある
  [ ] Player に PlayerController がある
  [ ] PlayerController に InputSystem_Actions がアサインされている
  [ ] Main Camera に CameraFollow がある
  [ ] DialogueSystem.prefab が置かれている

Tilemap
  [ ] Collision レイヤーに TilemapCollider2D + CompositeCollider2D がある
  [ ] 壁・障害物タイルが Collision レイヤーに配置されている

NPC（配置した場合）
  [ ] NPCTrigger に scenarioCSV がアサインされている
  [ ] BoxCollider2D が Is Trigger: オン になっている

マップ遷移（設定した場合）
  [ ] Target Scene Name が Build Settings のシーン名と一致している
  [ ] BoxCollider2D が Is Trigger: オン になっている
  [ ] スポーンポイントオブジェクトが遷移先シーンに存在する
```

### 再生して確認する内容

1. プレイヤーが WASD / 矢印キーで動く
2. カメラがプレイヤーを追う
3. 壁に当たって止まる
4. NPC に近づいてZキー（Interact）で会話が始まる
5. 遷移ポイントに乗るとフェードして別シーンに移動する

## よくある問題

### 「プレイヤーが動かない」

- PlayerController に InputSystem_Actions がアサインされているか確認
- Rigidbody2D の Body Type が Dynamic になっているか確認

### 「プレイヤーが壁を透過する」

- Collision レイヤーにタイルが配置されているか確認
- `TilemapCollider2D > Used By Composite` がオンか確認
- Player の CapsuleCollider2D が小さすぎないか確認

### 「カメラが動かない」

- Main Camera に CameraFollow がアタッチされているか確認
- Player オブジェクトのタグが「Player」になっているか確認（大文字小文字に注意）

### 「シーン遷移後にプレイヤーの位置がおかしい」

- 遷移先シーンにスポーンポイントオブジェクトが存在するか確認
- MapTransition の `Spawn Point Name` とスポーンポイントのオブジェクト名が完全一致しているか確認（大文字小文字含む）

### 「NPCに話しかけても会話が始まらない」

- NPCTrigger に `scenarioCSV` がアサインされているか確認
- BoxCollider2D の `Is Trigger` がオンか確認
- ScenarioExecutor（DialogueSystem Prefab の中）がシーンに存在するか確認
