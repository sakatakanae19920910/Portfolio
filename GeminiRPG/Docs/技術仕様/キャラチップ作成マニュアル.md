### シート内レイアウト（RPG Maker MV 2xスケール形式）

```
各キャラクターのフレーム配置（3列 × 4行 = 12フレーム）:

  列0       列1       列2
行0: 下_左足  下_中央  下_右足
行1: 左_左足  左_中央  左_右足
行2: 右_左足  右_中央  右_右足
行3: 上_左足  上_中央  上_右足

インデックス:
  _0, _1, _2  → 下方向アニメ
  _3, _4, _5  → 左方向アニメ
  _6, _7, _8  → 右方向アニメ
  _9, _10, _11 → 上方向アニメ
```

## 作画手順

### 4方向の描き分けポイント

| 方向 | 描き方 | ポイント |
|---|---|---|
| 下（正面） | 顔が見える | 最も描き込む・顔・胸の模様 |
| 左（横） | 横顔 | シルエット重視・髪型・輪郭 |
| **右（横）** | **左の水平反転でOK** | 非対称装備があれば修正 |
| 上（後ろ姿） | 顔なし | 後ろ髪・背中の服装 |

### 3フレーム歩行の構成

```
左足前 → 中央（立ち）→ 右足前
```

中央フレームを基準に、左右の足を交互に前に出す。

---

## デモ締切向け：最速案（推奨）

**「下3フレーム + 左3フレーム + 右は反転 + 上1枚」** で4方向アニメが成立。

| 方向 | 対応方法 | 工数 |
|---|---|---|
| 下 | 3フレーム描く | 2〜3h |
| 左 | 3フレーム描く | 1〜2h |
| 右 | SpriteRenderer.flipX でプログラム対応 | 0h |
| 上 | 後ろ姿1枚（アニメなし） | 0.5h |
| **合計** | | **3.5〜5.5h / 1キャラ** |

右向きは描かず、Unity 側でスクリプトから `spriteRenderer.flipX = true` で反転させる。

## Unity インポート手順

1. `Assets/Art/Characters/` に png を配置
2. Inspector で以下を設定：

| 設定項目 | 値 |
|---|---|
| Texture Type | Sprite (2D and UI) |
| Sprite Mode | Multiple |
| Pixels Per Unit | 48 |
| Filter Mode | Point (no filter) |
| Compression | None |

3. **Sprite Editor を開いて Slice**:
   - Type: `Grid By Cell Size`
   - Pixel Size X / Y: `96`
   - `Slice` → `Apply`

## Animator Controller の設定

### ステート構成（2D Blend Tree 推奨）

```
[Idle ステート] ← 2D Blend Tree (MoveX, MoveY)
  (0, -1) → Idle_Down
  (-1, 0) → Idle_Left
  (1, 0)  → Idle_Right
  (0, 1)  → Idle_Up

[Walk ステート] ← 2D Blend Tree (MoveX, MoveY)
  (0, -1) → Walk_Down
  (-1, 0) → Walk_Left
  (1, 0)  → Walk_Right
  (0, 1)  → Walk_Up

遷移:
  Idle → Walk : IsMoving == true
  Walk → Idle : IsMoving == false
```

### 遷移の設定値

| 設定 | 値 |
|---|---|
| Has Exit Time | OFF |
| Transition Duration | 0 |

PlayerController.cs はすでに `MoveX / MoveY / IsMoving` を Animator に送っているため、**Animator Controller を作るだけで動作する**。

### flipX 対応（右向きを描かない場合）

PlayerController.cs に以下を追記：

```csharp
// SpriteRenderer への参照を追加
private SpriteRenderer spriteRenderer;

void Awake()
{
    rb = GetComponent<Rigidbody2D>();
    spriteRenderer = GetComponent<SpriteRenderer>();
    // ...
}

void UpdateAnimation()
{
    if (animator == null) return;
    bool isMoving = moveInput.sqrMagnitude > 0.01f && canMove;
    animator.SetFloat("MoveX", lastDirection.x);
    animator.SetFloat("MoveY", lastDirection.y);
    animator.SetBool("IsMoving", isMoving);

    // 右向きは左向きアニメを反転して代用
    if (lastDirection.x > 0.1f)
    {
        animator.SetFloat("MoveX", -1f); // 左向きアニメを再生
        if (spriteRenderer != null) spriteRenderer.flipX = true;
    }
    else if (lastDirection.x < -0.1f)
    {
        if (spriteRenderer != null) spriteRenderer.flipX = false;
    }
}
```

## Animation Clip の作成

| クリップ名 | フレーム | ループ | Sample Rate |
|---|---|---|---|
| Walk_Down | _0 → _1 → _2 | Loop | 6〜8 fps |
| Walk_Left | _3 → _4 → _5 | Loop | 6〜8 fps |
| Walk_Up | _9 → _10 → _11 | Loop | 6〜8 fps |
| Idle_Down | _1（単フレーム） | Loop | — |
| Idle_Left | _4（単フレーム） | Loop | — |
| Idle_Up | _10（単フレーム） | Loop | — |

> 右向きは Walk_Left / Idle_Left を flipX で流用するためクリップ不要。
