# スプライトアニメーション作成マニュアル

**作成日**: 2026-05-20  
**対象**: フィールドの演出用アニメーション（ミタマ石キラキラ・本棚光り等）

---

## 全体の流れ

```
PNG インポート → スライス → Animation Clip 作成 → Animator Controller 作成 → GameObject に設定
```

---

## Step 1: PNG をインポートしてスライス

1. **PNG を Unity にドロップ**  
   `Assets/Art/Field/` フォルダに PNG をドラッグ＆ドロップ

2. **Texture Type を変更**  
   Project で PNG を選択 → Inspector で以下を設定：

   | 項目 | 値 |
   |---|---|
   | Texture Type | **Sprite (2D and UI)** |
   | Sprite Mode | **Multiple**（複数フレームの場合） |
   | Pixels Per Unit | **48**（プロジェクト統一値） |
   | Filter Mode | **Point (no filter)**（ドット絵はこれ） |

   右下の **Apply** を押す。

3. **Sprite Editor でスライス**  
   Inspector の **Sprite Editor** ボタンをクリック。

   - 上部メニュー **Slice** → Type: **Grid by Cell Size**
   - Cell Size: フレーム1枚分のピクセル数を入力（例: 48×48）
   - **Slice** ボタン → 右上の **Apply** で確定

   > フレームが1枚しかない場合は Sprite Mode を **Single** にして Sprite Editor 不要

---

## Step 2: Animation Clip を作成

1. **アニメーションを付ける GameObject を用意する**  
   Hierarchy で右クリック → Create Empty → 名前を `MitamaSparkle` 等にする

2. **Animation ウィンドウを開く**  
   メニュー: **Window → Animation → Animation**（またはショートカット Ctrl+6）

3. **GameObject を選択した状態で Create をクリック**  
   Animation ウィンドウに「Create」ボタンが出るので押す。  
   保存先: `Assets/Art/Field/` に `MitamaSparkle_Anim.anim` として保存

4. **フレームをタイムラインに並べる**  
   - Project でスライスした各フレームを **すべて選択**（Shift クリック）
   - Animation ウィンドウの **タイムライン（0:00 の位置）** にドラッグ

   フレームが並んだら完成。

5. **再生速度を調整する**  
   - タイムラインのフレームを右クリック → **Show Sample Rate** をオンにする
   - Samples（上部の数字）を変更して速さを調整  
     目安: キラキラなら **8〜12 fps**（デフォルト 60fps は速すぎる）

6. **ループ設定をオン**  
   Project で `.anim` ファイルを選択 → Inspector の **Loop Time** にチェック

---

## Step 3: Animator Controller を作成

Animation Clip 単体では動かない。「どのクリップを再生するか」を管理する **Animator Controller** が必要。

1. **Animator Controller を作成**  
   Project の `Assets/Art/Field/` で右クリック  
   → **Create → Animator Controller**  
   → 名前: `MitamaSparkle` 等

2. **Animator Controller を開く**  
   作成した Controller をダブルクリック → **Animator ウィンドウ**が開く

3. **Animation Clip を登録する**  
   Project から `.anim` ファイルを **Animator ウィンドウ** にドラッグ  
   自動的に **オレンジ色の Default State** になればOK

---

## Step 4: GameObject に Animator をセットする

1. **Animator コンポーネントを追加**  
   Hierarchy で演出用 GameObject を選択  
   Inspector → **Add Component → Animator**

2. **Controller をアサイン**  
   Animator コンポーネントの **Controller** 欄に、  
   Step 3 で作った Animator Controller をドラッグ

3. **SpriteRenderer も追加**（スプライトを表示するため必須）  
   Add Component → **Sprite Renderer**  
   > Sprite 欄は空でよい（Animator が自動的にフレームを切り替える）

4. **Play して確認**  
   Game ビューで再生し、キラキラが動いていれば完成！

---

## ミタマ石への組み込み方

アニメーション GameObject は **MitamaStone の子** として配置する。  
親（MitamaStone）が `SetActive(false)` になると子も一緒に消えるので、拾得処理は追加不要。

```
MitamaStone_Town01        ← MitamaStoneItem.cs がついている
└── MitamaSparkle         ← SpriteRenderer + Animator（キラキラアニメ）
```

**Sorting Layer / Order in Layer の設定**  
Sprite Renderer の Additional Settings で、マップタイルより手前に表示されるよう設定する。

| 設定 | 値 |
|---|---|
| Sorting Layer | Objects（または Default） |
| Order in Layer | タイル + 1（例: タイルが 0 なら 1 以上） |

---

## よくあるミス

| 症状 | 原因 | 対処 |
|---|---|---|
| アニメが動かない | Loop Time がオフ | `.anim` を選択して Loop Time にチェック |
| めちゃくちゃ速い | Samples が 60 のまま | Samples を 8〜12 に変更 |
| 表示されない | Sorting Order が低い | Order in Layer を上げる |
| 拾っても消えない | MitamaSparkle が子になっていない | Hierarchy で MitamaStone の子に移動 |
